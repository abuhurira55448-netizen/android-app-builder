# تطبيق القرآن الكريم

مشروع Android Java بسيط بواجهة داكنة ذهبية:
- قائمة 114 سورة.
- قراءة السور من الإنترنت بصيغة عثمانية.
- أذكار.
- عداد تسبيح.
- معلومات المطور وزر واتساب.

## بناء APK
افتح المشروع في Android Studio أو AndroidIDE واضغط Build APK.
أو ارفعه إلى GitHub وسيعمل GitHub Actions على بناء APK تلقائيًا.
