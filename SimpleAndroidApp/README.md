# Simple Android App

مشروع أندرويد بسيط جاهز للرفع على GitHub وبناء APK تلقائياً عبر GitHub Actions.

## طريقة البناء عبر GitHub
1. أنشئ Repository جديد في GitHub.
2. ارفع ملفات المشروع كلها.
3. افتح تبويب Actions.
4. شغّل Workflow باسم Build Android APK.
5. بعد انتهاء البناء، حمل APK من Artifacts.

## التشغيل محلياً
افتح المشروع في Android Studio ثم اضغط Run.
